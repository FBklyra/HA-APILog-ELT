# ADR-009 — Console SSO with Entra ID (OIDC) and four roles

- **Status:** Accepted
- **Date:** 2026-11-03
- **Author:** Freddy Beltran

## Context
Data and platform teams operate ALELT remotely; separation of duties is required.

## Decision
The console authenticates with Entra ID (OIDC, MSAL). Entra groups map to **Viewer, DataOperator, PlatformAdmin, Auditor**. The hub validates JWTs and enforces RBAC on every `/api/v1` call; mutating calls are audited.

## Consequences
- Dev-mode header `X-ALELT-Dev-Role` exists for local work only, accepted solely when `ALELT_DEV_AUTH=1`; never in production.
- Destructive/switch actions require confirmation text and a second approver.
