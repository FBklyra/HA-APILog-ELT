# ADR-010 — Db2 edge connects with CLI `SQLConnect` for `db2ReadLog`

- **Status:** Accepted — verified 2026-11-03, resolves OQ-05
- **Date:** 2026-11-03
- **Author:** Freddy Beltran

## Context
OQ-05: which connection type `db2ReadLog` needs from a C service (embedded SQL vs CLI).

## Decision
The Db2 edge plugin connects through Db2 CLI with `SQLConnect` (not `SQLDriverConnect`), then calls `db2ReadLog` on that connection context. Sequence (V2): connect → catalog SELECTs → `COMMIT` → `QUERY` → `READ` loop until sqlcode 2654.

## Evidence
Spike on a local test database (x64 process, `db2cli64.dll` + `db2app64.dll`) against a local test database: inserts, updates, deletes, commits and a rollback with CLRs read; non-DCC table absent (V1, V8).

## Consequences
- No embedded-SQL precompile step; plugin links CLI + db2app only.
- Process must be x64 (also works under ARM64 emulation on the dev laptop).
