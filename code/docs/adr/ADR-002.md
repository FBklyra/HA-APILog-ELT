# ADR-002 — Agent ships raw log records; decoding on the hub

- **Status:** Accepted
- **Date:** 2026-11-03
- **Author:** Freddy Beltran

## Context
The edge agent runs on the production Db2 server, where CPU and risk budget are minimal (P7).

## Decision
The agent frames raw `db2ReadLog` output into batches (zstd, sha256) and ships them unchanged. All decoding (row images, types, transactions) runs on the hub.

## Consequences
- Agent stays small and capped; decoder fixes need no agent redeploy.
- Raw bytes are retained → re-decode without touching Db2 (ADR-007).
- Hub needs a catalog snapshot versioned by position to decode correctly.
