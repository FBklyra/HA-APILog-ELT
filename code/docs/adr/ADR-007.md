# ADR-007 — Raw block archive in the destination stage

- **Status:** Accepted
- **Date:** 2026-11-03
- **Author:** Freddy Beltran

## Context
Decoder bugs and new mappings must be fixable without re-reading Db2 or re-snapshotting.

## Decision
Every received raw batch is archived in `ALELT_STAGE.RAW_ARCHIVE` (30–90 days, configurable) with its header and sha256.

## Consequences
- The reprocess-range runbook re-decodes from the archive; quarantine keeps `raw_ref` into it (R7).
- Storage cost bounded by retention; retention shown in the console.
