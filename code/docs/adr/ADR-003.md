# ADR-003 — Agent ↔ hub: outbound HTTPS with mutual TLS

- **Status:** Accepted
- **Date:** 2026-11-03
- **Author:** Freddy Beltran

## Context
No listening port is allowed on the Db2 server (R4); the hub may only send whitelisted commands (R5).

## Decision
The agent opens all connections: HTTPS via WinHTTP with a client certificate from the Windows certificate store (mTLS), plus an agent-initiated WebSocket control channel. Protocol versioned by `X-ALELT-Protocol: 1`. The hub pins agent certificate thumbprints.

## Consequences
- Hub NSG allows inbound 443 only from the Db2 server IP and the admin range.
- Internal PKI enrollment and expiry monitoring (alert 30 days before) are required.
- Commands are typed, whitelisted models; unknown commands fail validation on both sides.
