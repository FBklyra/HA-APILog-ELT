# ADR-006 — Stable view layer and per-table switch

- **Status:** Accepted
- **Date:** 2026-11-03
- **Author:** Freddy Beltran

## Context
Cutover must be per table, reversible in minutes and invisible to dbt (R2).

## Decision
dbt reads `ERP_RAW` views only. `ALELT_CONTROL.SWITCH_SOURCE(table, 'LEGACY'|'ALELT')` repoints a view. The legacy pipeline keeps running until L10.

## Consequences
- Rollback target < 5 min, drilled per wave (L9).
- dbt role gets SELECT on `ERP_RAW` only; no grants changed on legacy-pipeline objects.
- Switch actions are two-person, confirmed and audited in the console.
